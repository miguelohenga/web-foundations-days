About QuickNotes

QuickNotes is a simple note-taking app designed to help you capture ideas, tasks, and reminders instantly. It is fast, lightweight, and works offline.

How to Use QuickNotes

  1. Open the QuickNotes app on your device.
  2. Tap the "+" button to create a new note.
  3. Type your note and tap save.

Features

  • Create notes instantly
  • organize with tags
  • works offline
  • sync across devices

Keyboard Shortcuts

Shortcut Action
Ctrl + N New note
Ctrl + S Save note
Ctrl + F Find note
